# Vibe_Cowork_Thinking Service Roadmap

## 서비스 목표

여러 AI 에이전트가 협업한 결과를 비교하고, 프로젝트 단위로 운영 규칙을 만들 수 있는 실험 워크스페이스로 발전시킵니다.

## Priority 1

- 워크스페이스 권한과 실행 예산을 프로젝트 단위로 분리합니다.
- 결과 diff와 에이전트별 출력 비교 화면을 만듭니다.
- 작업 감사 로그와 승인 흐름을 정리합니다.

## Priority 2

- Runner와 Orchestrator의 역할 구분을 더 명확히 시각화합니다.
- 결과 요약과 실패 원인 비교를 리포트로 보여줍니다.
- 실험 템플릿과 반복 가능한 실행 프리셋을 추가합니다.

## Ops

- 모델 비용과 실행 시간을 추적하는 기준을 문서화합니다.
- 장애 시 재실행 순서와 수동 개입 포인트를 정리합니다.
